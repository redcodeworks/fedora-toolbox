# Fedora's own repositories (fedora, updates). Installed by install.sh as ONE strict dnf5 call: a package
# that cannot be installed fails the build. One entry per line: "name", "name.arch" or "@group";
# blank lines and #-comments are ignored. Used by the fedora-gaming toolbox and by the gx host image.
#
# Every name resolved on Fedora 45 (repoquery, 2026-11-16); the toolbox base is Fedora 44, where the
# same names exist (CI is the proof, the toolbox build installs this list).
# Every .i686 entry has its .x86_64 sibling named explicitly: a bare name next to a name.i686 made dnf5 on
# a host install ONLY the i686 package (the lint and tests/package-manifests.sh enforce the pairing).
# Install this list BEFORE negativo17.txt (Steam's 32-bit dependencies, Mesa included, then come from here
# unless negativo17 has a newer build, which it does for Mesa; see README.md).
